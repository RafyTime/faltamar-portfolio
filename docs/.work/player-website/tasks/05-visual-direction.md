## Question

Which visual direction expresses this goalkeeper's personality while making the agreed content easy to use?

Use official athlete research, family preferences, and the chosen first-version content to create a rough prototype for human feedback. Explore action photography, typography, color, and a small amount of purposeful interaction. Consider mobile use and Spanish and English text. Label any placeholders clearly. The prototype is an exploration asset, not the production website; resolve through feedback rather than the agent choosing alone.
